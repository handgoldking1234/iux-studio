# 빅트리소프트(BigTreeSoft) 홈페이지 리뉴얼 시안

교육 솔루션 기업 빅트리소프트의 홈페이지 리뉴얼 퍼블리싱 시안입니다.
순수 HTML/CSS + 간단한 스크립트로 작성했고, 개발 소스는 포함하지 않았습니다.

## 구성
- `index.html` — 전체 페이지(해시 라우팅 원페이지)
- `img/` — 히어로·도입사례·스토리·솔루션·채용·회사소개 이미지

## 페이지
| 해시 | 화면 |
|---|---|
| `#home` | 메인 (히어로 슬라이더, Works, Story) |
| `#reference` | 도입 사례 (검색·카테고리 필터) |
| `#consulting` | 온라인 상담 신청 / 도입 절차 (확인·완료 팝업) |
| `#story`, `#story-1`~`9` | 스토리 목록 / 상세 |
| `#solution` | 솔루션 소개 (탭별 이미지) |
| `#recruit` | 채용 |
| `#about` | 회사 소개, 연혁, 조직, CI, 오시는 길 |

## 참고
- 아이콘: [Lucide](https://lucide.dev) (unpkg CDN)
- 폰트: Plus Jakarta Sans, Noto Sans KR (Google Fonts)
- 오시는 길 지도: 실제 도메인에서는 구글 지도 iframe이 자동으로 표시되고, 미리보기 환경에서는 약도가 표시됩니다.
- 이미지는 AI 생성 시안용이며, 일부에 실제 기업 로고·깨진 문자가 있어 운영 전 교체가 필요합니다.
- 도입 사례·스토리 게시물·복리후생·연혁 일부는 샘플 콘텐츠입니다.
